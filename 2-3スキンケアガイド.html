🤔 スキンケアの目的

スキンケア = 肌を清潔に保ち、潤いを与えて、健康な状態を維持すること

なぜ必要？
・何もしないと皮脂・汚れが溜まる → ニキビ・肌荒れ
・乾燥したまま放置 → シワ・くすみ
・紫外線ダメージ蓄積 → シミ・老化
→ つまり、スキンケアしないと「不潔」で「老けて」見えます

🎯 スキンケアの基本は3ステップ

🧼
STEP1: 洗う
汚れ・皮脂を落とす
💧
STEP2: 潤す
水分を補給する
🔒
STEP3: 守る
水分を閉じ込める

この3ステップを朝・夜の1日2回やるだけ！

☀️ 朝のルーティン（5分）

起床後、顔を洗う前にチェック！
1
洗顔
時間：2分
📚 なぜ必要？

寝ている間に分泌された皮脂・汗・ホコリを落とすため。
朝洗顔しないと → 皮脂が酸化 → ニキビ・肌荒れの原因に。

🔧 やり方（超詳細版）
手を洗う
まず石鹸で手を洗う。汚れた手で顔を触ると雑菌が顔につきます。
ぬるま湯で顔を濡らす
温度：30-35度（触って「ちょっと冷たい」くらい）
❌NG：熱いお湯 → 必要な皮脂まで落ちて乾燥する
洗顔料を泡立てる
方法1：泡立てネット（100円）を使う
方法2：ホイップ状の洗顔料を買う（泡立て不要）
泡の量：手のひらいっぱい（レモン1個分くらい）
❌NG：泡立てずに直接顔につける → 摩擦で肌が傷つく
泡で優しく洗う（30秒）
洗う順番：Tゾーン（おでこ・鼻）→ 頬 → 目元・口元
洗い方：円を描くようにクルクル。指の腹で優しく。
❌NG：ゴシゴシこする → 摩擦で肌が傷つく
ぬるま湯でしっかりすすぐ（1分）
すすぎ回数：20-30回
注意ポイント：髪の生え際・フェイスライン・あごは泡が残りやすい
❌NG：すすぎ不足 → 洗顔料が残ってニキビの原因に
清潔なタオルで拭く
拭き方：タオルを顔に当てて「ポンポン」と押さえる
❌NG：タオルでゴシゴシ拭く → 摩擦で肌が傷つく
💡 初心者向けワンポイント

「泡立てがめんどくさい」という人へ
→ ホイップ状の洗顔料（MINON アミノモイストジェントルウォッシュホイップ ¥1,650）を買えば泡立て不要！

❌ 絶対やってはいけないNG行動
  • 泡立てずに直接顔につける
  • 熱いお湯で洗う
  • ゴシゴシこする
  • すすぎを適当にする
  • 同じタオルを何日も使う（雑菌だらけ）
2
化粧水
時間：1分 / 洗顔後すぐ！
📚 なぜ必要？

洗顔後の肌は水分が蒸発しやすい状態。
化粧水で肌に水分を補給します。
❌ 化粧水をつけないと → 肌が乾燥 → カサカサ・くすみの原因に

適量
⭕️
500円玉大
🔧 やり方（超詳細版）
手のひらに500円玉大を出す
コットンは使わなくてOK（手で十分）
両手に広げる
両手のひらで化粧水を温めるイメージ（体温で浸透しやすくなる）
顔全体に優しくパッティング
つける順番：頬 → おでこ → 鼻 → あご → 目元・口元
つけ方：「ポンポン」と優しく押し込む（5-10回）
❌NG：パンパン叩く → 肌が傷つく
首にも塗る
首も顔と同じくらい見られる部分。忘れずに。
手のひらで顔を包む（10秒）
手の温度で化粧水を肌に浸透させる
💡 初心者向けワンポイント

「500円玉大って多すぎじゃない？」と思う人へ
→ ケチると効果ゼロ。1回500円玉大が適量です。足りないと感じたら追加してOK。

❌ 絶対やってはいけないNG行動
  • 洗顔後10分以上経ってからつける（すぐつけないと乾燥する）
  • パンパン叩きつける
  • 量をケチる（効果が出ない）
  • 化粧水だけで終わる（次の乳液が必須！）
3
美容液
時間：30秒
📚 なぜ必要？

美容液は肌の悩みに特化した成分が濃縮されたアイテム。
・ニキビ → ビタミンC配合の美容液
・くすみ・シミ → 美白成分配合の美容液
・乾燥 → 保湿成分配合の美容液
初心者は「ビタミンC配合」を選べばOK（万能）

適量
⭕️
パール粒1つ分
🔧 やり方（超詳細版）
手のひらにパール粒1つ分を出す
商品によって量が違うので、パッケージ記載の量を確認
両手に広げる
両手のひらで温める
顔全体に伸ばす
つける順番：化粧水と同じ（頬 → おでこ → 鼻 → あご → 目元・口元）
つけ方：優しく押し込むように
特に気になる部分は重ね塗り
ニキビ跡・シミ・くすみが気になる部分は、もう一度重ねてつける
💡 初心者向けワンポイント

「美容液って高いから買いたくない」という人へ
→ 最初の30日は美容液なしでもOK。慣れてきたら追加してください。
→ ただし、ニキビ・シミで悩んでいる人は最初から使うのを強く推奨！

4
乳液
時間：1分
📚 なぜ必要？

化粧水・美容液で補給した水分を「フタ」で閉じ込めるため。
乳液には油分が含まれていて、これが肌表面に膜を作る。
❌ 乳液をつけないと → 化粧水が蒸発 → 意味がない

適量
⭕️
10円玉大
🔧 やり方（超詳細版）
手のひらに10円玉大を出す
乳液は化粧水より少なめでOK
両手に広げる
手のひらで温める
顔全体に伸ばす
つける順番：乾燥しやすい部分から（頬 → おでこ → あご → 鼻 → 目元・口元）
つけ方：優しく伸ばす。ベタベタするくらいでOK（すぐ馴染む）
❌NG：Tゾーン（おでこ・鼻）につけすぎる → テカる
乾燥しやすい部分は重ね塗り
目元・口元は特に乾燥しやすいので、もう一度重ねてOK
手のひらで顔を包む（10秒）
手の温度で乳液を肌に浸透させる
💡 初心者向けワンポイント

「乳液をつけるとベタベタする」という人へ
→ 最初はベタつくけど、1-2分で馴染みます。我慢してください。
→ どうしてもベタつきが嫌な人は、量を減らしてもOK（ただし効果は下がる）

❌ 絶対やってはいけないNG行動
  • 乳液をつけない（化粧水が蒸発して意味なし）
  • ベタつきが嫌だからと極端に少量にする
  • Tゾーンにつけすぎる（テカる原因）
5
日焼け止め
時間：30秒 / 朝のみ
📚 なぜ必要？

紫外線は肌の最大の敵。
紫外線を浴び続けると → シミ・シワ・くすみ・たるみの原因に。
しかも紫外線ダメージは蓄積する（30代40代で一気に出てくる）
❌ 日焼け止めをつけないと → 10年後に後悔する

適量
⭕️
パール粒2つ分
🔧 やり方（超詳細版）
手のひらにパール粒2つ分を出す
ケチると効果ゼロ。たっぷり使う。
顔全体に伸ばす
つける順番：頬 → おでこ → 鼻 → あご → 首
つけ方：ムラなく塗る。白浮きしてもOK（すぐ馴染む）
耳・首の後ろも忘れずに
耳・首は忘れがち。でも日焼けしやすい部分なので必ず塗る。
💡 初心者向けワンポイント

「室内にいるから日焼け止め不要」は大間違い
→ 窓から紫外線は入ってきます。曇りの日も紫外線は降り注いでいます。
→ 毎日塗るのが鉄則。「外出する日だけ」はNG。

❌ 絶対やってはいけないNG行動
  • 「今日は室内だから」と塗らない
  • 量をケチる（効果がゼロになる）
  • 朝塗って夜まで塗り直さない（3-4時間おきに塗り直すのが理想）

0
クレンジング
時間：2分 / メイクする人のみ
📚 なぜ必要？

メイク・日焼け止めは洗顔料だけでは落ちません。
クレンジングで油性の汚れ（メイク・日焼け止め）を落とす。
❌ クレンジングしないと → 毛穴詰まり → ニキビ・肌荒れの原因

💡 メイクしない人も日焼け止めを塗ったらクレンジング必要？

→ 商品による。
・「石鹸で落ちる」と書いてあれば不要
・書いてなければクレンジング推奨
おすすめの日焼け止め（ビオレUV）は石鹸で落ちるのでクレンジング不要

適量
⭕️
さくらんぼ大
🔧 やり方（超詳細版）
手を洗う
まず手を清潔に
乾いた手にクレンジングをさくらんぼ大出す
❌NG：手が濡れた状態でクレンジングをつける → 効果半減
乾いた顔全体に馴染ませる（1分）
馴染ませる順番：Tゾーン → 頬 → あご → 目元・口元
馴染ませ方：円を描くようにクルクル。メイクが浮いてくる感覚がある。
❌NG：ゴシゴシこする
ぬるま湯で乳化させる
少量のぬるま湯を手に取り、顔全体に馴染ませる。
クレンジングが白く濁ったらOK（これを「乳化」という）
ぬるま湯でしっかりすすぐ（1分）
20-30回すすぐ。ヌルヌルが完全に取れるまで。
💡 初心者向けワンポイント

「オイルクレンジング」「ジェルクレンジング」どっちがいい？
→ 初心者は「ジェルクレンジング」がおすすめ（肌に優しい）
→ 無印良品のマイルドジェルクレンジングが安くて優秀

🌙 夜の洗顔・化粧水・美容液・乳液

基本的に朝と同じ手順ですが、以下の点だけ違います：

項目 朝 夜
クレンジング なし メイクする人のみ
洗顔 軽め しっかり（1日の汚れを落とす）
化粧水 500円玉大 多めでもOK（1円玉×2）
美容液 パール粒1つ 同じ
乳液 10円玉大 乾燥肌の人は多めでもOK
日焼け止め 必須 なし
💡 夜のポイント
・洗顔はTゾーン（おでこ・鼻）を特に念入りに
・化粧水・乳液は朝より多めに塗ってもOK
・寝ている間に肌は修復されるので、夜のスキンケアは超重要
